# Лагерь у костра

Планировщик дня в духе классического фэнтези. Задачи дня это спутники у костра, большие цели это походы на логова, а просроченные задачи встают нежитью на лесной дороге. Весь день помещается на одном экране телефона, план собирается на отдельном.

## Запуск

Нужен Node.js 22.12 или новее (подойдёт и 20.19+).

```
npm install
npm run dev
```

Откроется на http://localhost:5173. В консоли будет строка `Network: http://192.168.…:5173`: этот адрес открывается с телефона, если он в той же сети Wi-Fi.

- `npm test` прогоняет автотесты (32 теста: правила, день, хранение, сохранение в GitHub).
- `npm run build` собирает сайт в `dist/`, `npm run preview` показывает собранный.

## Телефон и компьютер: сохранение в GitHub

Игра всегда хранится в браузере. Чтобы телефон и компьютер видели одну и ту же игру, её можно сохранять в секретный гист на GitHub.

1. В игре открой «Летопись» → «Сохранение в GitHub» → «Создай токен на GitHub». Откроется страница GitHub, где уже выбраны название, срок на год и единственное право «Gists: Read and write». Внизу нажми «Generate token».
2. Скопируй токен (начинается с `github_pat_`), вставь в поле и нажми «Подключить». Если гиста с сохранением ещё нет, игра создаст его сама.
3. На втором устройстве вставь тот же токен. Сохранение найдётся по имени файла `taskcraft-lager.json`, id гиста вводить не надо. Если там в браузере ещё ничего не делали, игра просто возьмёт сохранение из GitHub.

Как это работает (`src/sync/`, `src/game/merge.ts`):

- После каждого действия игра через несколько секунд пишет сохранение в гист, а при запуске, при возвращении в приложение и раз в две минуты смотрит, не сохранило ли что-то другое устройство.
- Если с прошлой встречи менялись обе стороны (например, телефон был без сети), версии сливаются: задачи и походы с обеих сторон остаются, у одной задачи разные поля берутся оттуда, где их меняли, золото, опыт и итоги дня складываются. Если одно и то же поле поменяли на обоих устройствах, остаётся то, что сделано позже.
- Таймер, мана и смена дня досчитываются каждым устройством одинаково, поэтому время, начатое на компьютере, на телефоне идёт дальше, а не удваивается.
- Если в гисте другая игра, игра спросит, какую оставить. Копия из файла («Загрузить копию») уходит в GitHub целиком, без слияния.
- Без сети игра работает как обычно, сохранение догонит, когда сеть появится.
- Токен хранится только в браузере этого устройства и в копию сохранения не попадает. Пароля у него нет: на чужом компьютере лучше не подключать.

## Сайт на GitHub Pages

Чтобы открывать игру с телефона откуда угодно, её можно выложить на GitHub Pages.

1. Поставь на место файл публикации. GitHub ищет его в `.github/workflows/`, а в проекте он лежит в `ci/deploy.yml`. В PowerShell или cmd из папки проекта:
   ```
   mkdir .github\workflows
   move ci\deploy.yml .github\workflows\
   rmdir ci
   ```
2. Создай репозиторий на GitHub. На бесплатном тарифе Pages работает только у публичных репозиториев; сохранение игры при этом лежит в секретном гисте, а не в репозитории.
3. Залей проект:
   ```
   git init
   git add .
   git commit -m "Лагерь у костра"
   git branch -M main
   git remote add origin https://github.com/ЛОГИН/РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
4. В репозитории: Settings → Pages → Source: **GitHub Actions**. Первая публикация при пуше могла упасть, пока Pages был выключен: запусти её заново в Actions → «Публикация» → Run workflow.

Дальше каждый пуш в `main` проверяет тесты, собирает и публикует сайт (`.github/workflows/deploy.yml`) по адресу `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`. На телефоне открой его и добавь на главный экран: в Chrome меню ⋮ → «Добавить на главный экран», в Safari «Поделиться» → «На экран Домой». Игра откроется без адресной строки и запустится и без сети.

## Правила

- **Спутники.** Задача это спутник одного из четырёх классов по размеру: I разбойник (до получаса), II варвар (пара часов), III маг (целый день), IV рыцарь (несколько дней). Класс подбирается по оценке времени, его можно поправить при сдаче.
- **Утро.** На экране «План» собираешь отряд на день и разжигаешь костёр: +3 опыта за каждого позванного. Лягушка дня это самая тяжёлая задача, опыт за неё удваивается.
- **День.** Позванный к огню спутник работает, таймер идёт в задачу. «Готово» даёт 25 золота за уровень и опыт (25, 40, 60, 85 по уровням), а логову похода урон, равный уровню. Когда открытых задач в походе не осталось, логово пало: поход можно отправить в зал трофеев.
- **Мана.** Утром 100. Работа тратит 15 в час, привал возвращает 30 в час, задача из другого похода стоит 5. Вечером или в выходной после работы раз в день можно взять второе дыхание: +30.
- **Смены.** Утро, рабочий день, вечер, выходной и ночь (за 30 минут до отбоя). Днём впереди рабочие походы, вечером личные. Распорядок меняется в «Летописи».
- **Нежить.** Просроченная задача встаёт на дороге: скелет-миньон с первого дня, разбойник с третьего, воин с седьмого, маг с четырнадцатого.
- **Вестник.** Задача без похода и без дня приходит письмом, его разбирают в плане.
- **Забытый таймер.** Если 90 минут не заглядывать в игру, таймер встанет сам и спросит, шла ли работа.
- **Отбой.** Итоги дня: кого оставить у костра на завтра, остальные возвращаются в отряд. Игровой день начинается в 4 утра.

Все числа лежат в `src/game/rules.ts`.

## Как устроено

| Где | Что |
| --- | --- |
| `src/game/` | правила без интерфейса: состояние, время и смены, награды, вид дня (`view.ts`), хранилище, слияние версий |
| `src/sync/` | сохранение в GitHub: клиент гистов и синхронизация |
| `src/ui/` | экраны на Preact: лагерь, план, королевство, летопись, листы задач |
| `src/scene/` | описание картинки лагеря: где фон, фигуры и места |
| `public/camp/` | отрендеренные картинки лагеря |
| `scripts/render-camp/` | сцена на three.js и скрипты, которые её снимают |
| `tests/` | автотесты (vitest) |

## Картинки лагеря

Лагерь нарисован заранее: 3D-сцена из моделей KayKit снимается в картинки для дня, вечера и ночи, а каждая фигура на каждом месте отдельной картинкой с прозрачным фоном. На телефоне нет 3D, поэтому всё работает быстро и не сажает батарею.

Переснять (нужен git и Chrome или Edge):

```
cd scripts/render-camp
npm install
npm run models     # скачивает модели KayKit в kaykit/
npm run preview    # три пробных кадра в out/
npm run render     # картинки в public/camp/ и src/scene/camp.json
npm run icons      # значки приложения из ночного костра
```

Камера, свет, места и позы задаются в `scripts/render-camp/scene/camp.js`.
